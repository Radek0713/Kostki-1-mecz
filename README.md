# Kostki 1 mecz

[PL] Jeden mecz 2 wybranych przez użytkownika drużyn (nazwa i siła), generuje wynik 1 meczu oraz kursy bukmacherskie na popularne wydarzenia. Mecz generowany wg autorskiego algorytmu.

[EN] A match between two user-selected teams (defined by name and strength) generates a match result and betting odds for popular markets. The match is generated using a proprietary algorithm.
